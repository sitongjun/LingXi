# 灵犀居家管家 —— 接口设计

版本 0.1（M1），2026-10-13

## 1. 系统组成

| 节点 | 硬件 | 工程 | 职责 |
|---|---|---|---|
| 家居主控 | 普中 STM32F103ZET6 | `stm32/LingXi_STM32` | 传感器、执行器、本地规则、按键、3.5 寸屏 |
| 语音终端 | 正点原子 DNESP32S3 | [LingXi_ESP32](https://github.com/sitongjun/LingXi_ESP32)（板型 `lingxi-dnesp32s3`） | 语音对话、MCP 工具、联网 |

## 2. 硬件连接

| STM32 | DNESP32S3（EX IO 排针 P1） | 说明 |
|---|---|---|
| PB10（USART3_TX） | IO18（UART1_RX） | STM32 → ESP32 |
| PB11（USART3_RX） | IO17（UART1_TX） | ESP32 → STM32 |
| GND | GND | 必须共地 |

- 两边都是 3.3V 电平，直接连接。
- STM32 板右上角 `PB10T/W_TX`、`PB11R/W_RX` 两组跳线帽必须拔掉，使 PB10/PB11 与 RS232/WiFi 接口断开。
- DNESP32S3 的 IO35/36/37 被 PSRAM 占用，不可使用。

## 3. STM32 板引脚（实测）

| 资源 | 引脚 | 有效电平 |
|---|---|---|
| DS0（客厅灯） | PB5 | 低电平亮 |
| DS1（卧室灯） | PE5 | 低电平亮 |
| 蜂鸣器 | PB8 | 高电平响 |
| KEY_UP | PA0 | 按下为高 |
| K1 / K2 / K3 | PE2 / PE3 / PE4 | 按下为低 |
| 调试串口 | USART1 PA9/PA10（板载 CH340） | 115200 8N1 |

注意：手头的 PZ6806L 原理图与实物不完全一致（实物 PB5 为 DS0、PB8 为蜂鸣器），新引脚以实测为准。

## 4. 串口帧协议

USART3 / UART1，115200 8N1。

```
| 0xAA | 0x55 | LEN_L | LEN_H | CMD | SEQ | PAYLOAD (LEN 字节) | CRC_L | CRC_H |
```

- `LEN`：PAYLOAD 长度，小端，最大 1024。
- `CRC`：CRC16-CCITT（多项式 0x1021，初值 0xFFFF），计算范围 `LEN_L` 到 PAYLOAD 末尾，小端。
- 应答帧 `CMD = 请求 CMD | 0x80`，`SEQ` 与请求相同。
- ESP32 发出请求后等待 300ms（能力清单 500ms），超时重发，最多 3 次。
- 接收端字节间隔超过 50ms 丢弃半帧，重新找帧头。

### 4.1 命令表

| CMD | 方向 | 请求 PAYLOAD | 应答 PAYLOAD |
|---|---|---|---|
| 0x01 PING | ESP→STM | 无 | `uptime_ms` u32 LE |
| 0x02 GET_CAPS | ESP→STM | 无 | 能力清单 JSON |
| 0x03 SET | ESP→STM | `dev_id` u8，`value` s16 LE | `status` u8，`dev_id` u8，`value` s16 LE |
| 0x04 GET_STATE | ESP→STM | 无 | 状态 JSON |
| 0x40 EVENT | STM→ESP | 事件 JSON | 无需应答 |

SET 状态码：0 成功，1 设备不存在，2 数值越界，3 长度错误。

### 4.2 能力清单（设备自描述）

```json
{"node":"stm32_home","fw":"0.1.0","devices":[
  {"id":1,"name":"living_light","desc":"Living room light (DS0 on board)","type":"switch","min":0,"max":1},
  {"id":2,"name":"bedroom_light","desc":"Bedroom light (DS1 on board)","type":"switch","min":0,"max":1},
  {"id":3,"name":"alarm","desc":"Buzzer alarm. ...","type":"switch","min":0,"max":1}]}
```

- `type`：`switch`（0/1）或 `level`（min..max）。
- ESP32 启动时读取能力清单，为每个设备生成 MCP 工具 `self.home.<name>.set`：
  - `switch` 类型参数为 `on`（boolean）；
  - `level` 类型参数为 `level`（integer，范围取自 min/max）。
- 另有固定工具 `self.home.get_state` 返回状态 JSON。
- **STM32 新增设备只需在 `home.c` 的设备表加一行，ESP32 端无需修改。**

### 4.3 状态与事件

```json
{"living_light":1,"bedroom_light":0,"alarm":0,"uptime_s":123}
{"src":"key","dev":"living_light","value":1}
```

## 5. STM32 本地按键

| 按键 | 功能 |
|---|---|
| K1 | 切换客厅灯 |
| K2 | 切换卧室灯 |
| K3 | 切换报警 |
| KEY_UP | 全部关闭 |

本地操作会通过 EVENT 上报，ESP32 屏幕显示提示。

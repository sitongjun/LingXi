## 3. 下次上电怎么继续

1. 两块板用 USB 接电脑：STM32 走 **COM7**（CH340），DNESP32S3 走 **COM12**（板载 USB）。COM 号随插口可能变化。
2. 连线保持：STM32 `PB10 → IO18`、`PB11 ← IO17`、`GND – GND`；STM32 右上角 `PB10T/W_TX`、`PB11R/W_RX` 两个跳线帽保持拔掉。
3. STM32 编译下载（必须用 GCC，Keil 评估版有 32KB 限制）：
   ```powershell
   cd D:\project\LingXi
   python tools\build_stm32.py stm32\LingXi_STM32
   D:\idf\Espressif\python_env\idf5.3_py3.11_env\Scripts\python.exe tools\stm32_isp.py COM7 flash stm32\LingXi_STM32\build_gcc\LingXi.hex
   ```
4. ESP32 编译下载（ESP-IDF **5.4.2**）：
   ```powershell
   $env:IDF_TOOLS_PATH="D:\idf\Espressif"
   $env:PATH="D:\idf\Espressif\python_env\idf5.4_py3.12_env\Scripts;$env:PATH"
   . D:\idf\Espressif\frameworks\esp-idf-v5.4.2\export.ps1
   cd D:\esp32\LingXi_ESP32
   idf.py build
   idf.py -p COM12 flash
   ```
5. 改了屏幕上的中文文字后，先运行 `python tools\gen_font.py stm32\LingXi_STM32` 重新生成字库。

## 5. 已踩过的坑

- 手头的 PZ6806L 原理图与实物不一致（实物 PB5=DS0、PB8=蜂鸣器），新引脚一律先实测。
- 屏幕标签 ILI9488，0xD3 读出 0x9486；该模块按 8 位传输，每像素写两次。
- Keil 评估版 32KB 限制 → 用 ARM GCC（`D:\tools\arm-gnu-toolchain`）。
- 源码为 UTF-8；Keil 打开前设置 Edit → Configuration → Editor → Encoding 为 UTF-8。
- ESP-IDF 5.4.2 子模块曾不完整，已修复；`image_player 1.1.0~1` 已从组件仓库下架，改用 `local_components` 本地副本。
